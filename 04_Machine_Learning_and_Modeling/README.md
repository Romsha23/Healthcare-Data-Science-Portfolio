# Phase 4: Machine Learning & Modeling

The final phase uses the engineered datasets to build predictive models, with a heavy emphasis on clinical interpretability and handling real-world data distributions.

**Key Objectives:**
* Train a regularized Logistic Regression model to predict 30-day hospital readmissions.
* Evaluate model performance using Accuracy, Confusion Matrices, and ROC-AUC curves.
* Assess model calibration to ensure probability scores are trustworthy for clinical triaging.
* Handle severe class imbalances (common in medical data) using dynamically weighted loss functions.
